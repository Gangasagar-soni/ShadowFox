# Resume File

Please add your resume as `Gangasagar_soni.pdf` in this directory.

The application will serve this file when users click the "Download Resume" button.

To add your resume:
1. Save your resume as a PDF file
2. Name it `Gangasagar_soni.pdf`
3. Place it in this `public/` folder
4. The app will automatically serve it at `/Gangasagar_soni.pdf`

The resume paths in the components have been updated to correctly reference `/Gangasagar_soni.pdf`.
