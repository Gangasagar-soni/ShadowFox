## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Gangasagar-soni/ShadowFox/Portfolio
```

2. Navigate to the project folder

```bash
cd Portfolio
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm start
```
